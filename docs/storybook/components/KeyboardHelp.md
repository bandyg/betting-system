# KeyboardHelp

全局快捷键帮助 modal — 按 `?` 打开。

## 触发
- 全局 keydown `?` (Shift+/)
- Header 的 ⌨️ 按钮

## 关闭
- `Esc`
- 点击 ✕

## 快捷键列表

| 键 | 作用 |
|----|------|
| `1` / `2` / `3` | 选第 N 个 odds chip |
| `Enter` | 投注单提交下注 |
| `/` | 聚焦搜索框 |
| `?` | 打开/关闭本 modal |
| `Esc` | 关闭任何 modal |
