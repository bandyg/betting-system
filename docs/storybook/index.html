useKeyboard

全局键盘快捷键 hook — 输入框聚焦时大部分快捷键不触发，Esc 任何时候都生效。

注册快捷键
const kbd = useKeyboardShortcuts();
// kbd.helpOpen / kbd.openHelp() / kbd.closeHelp()
// ? 打开 / Esc 关闭

useVirtualScroll

虚拟滚动 hook — ResizeObserver + scroll listener + requestAnimationFrame 节流。<40 项时退化全渲染。

用法
const { visible, totalHeight, useVirtual } = useVirtualScroll({
  items, parentRef, itemHeight: 96, overscan: 4, threshold: 40,
});

useToast / useTheme

zustand store 封装 — 大多数场景用静态方法 toast.ok('text') 而非 hook。
